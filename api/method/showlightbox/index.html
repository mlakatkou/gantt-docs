showLightbox

Description​

Opens the lightbox for the specified task

showLightbox: (id: string | number) => void

Parameters​

  • id - (required) string | number - the task id

Example​

gantt.showLightbox(1);/*!*/

gantt.hideLightbox();

Details​

The method invokes the onBeforeLightbox and onLightbox events.
