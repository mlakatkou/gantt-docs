drag_resize

Description​

Ermöglicht das Ändern der Größe von Aufgaben mittels Drag-and-Drop

drag_resize: boolean

Example​

gantt.config.drag_resize = false;
gantt.init("gantt_here");

Default value: true

Details​

Anleitungen zum Entfernen der Resize-Handles von allen Aufgaben finden Sie im entsprechenden Abschnitt der CSS-Dokumentation.

Für eine detailliertere Steuerung beim Ändern der Größe von Aufgaben siehe den Artikel Dragging Tasks within the Timeline, der folgende Themen behandelt:

  • Deaktivieren der Größenänderung für bestimmte Aufgaben
  • Ermitteln, welche Seite einer Aufgabe geändert wird
  • Deaktivieren der Größenänderung des Start- oder Enddatums einer Aufgabe
