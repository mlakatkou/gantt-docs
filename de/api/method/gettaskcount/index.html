getTaskCount

Description​

Gibt die Gesamtanzahl der aktuell im Gantt-Chart geladenen Aufgaben zurück

getTaskCount: () => number

Returns​

  • count - (number) - die Gesamtanzahl der Aufgaben im Zeitplan

Example​

gantt.getTaskCount();
