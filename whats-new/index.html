9.2​

Minor update

Breaking Changes​

This update brings some changes in the behavior of framework wrappers. Make sure to check the Migration notes to be on the safe side.

New Functionality​

  • React Gantt, Vue Gantt, and Angular Gantt wrappers now HTML-escape string values returned from template functions by default to prevent XSS attacks. This applies to templates, config.columns[].template, and config.scales[].format functions

  • Updated TypeScript typings: added SerializedTask, SerializedLink, SerializedBaseline, SerializedResourceAssignment, and GanttData types. See the Data Model overview for details
