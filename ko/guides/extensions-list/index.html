확장 기능 전체 목록

dhtmlxGantt는 기본 기능을 확장하는 다양한 확장 기능(Extensions)을 제공합니다.

확장 기능을 활성화하려면 gantt.plugins 메서드를 사용하여 플러그인을 활성화하면 됩니다.

고급 드래그 앤 드롭​

이 확장 기능을 사용하면 드래그 앤 드롭을 통해 작업을 생성하고 선택할 수 있습니다.

gantt.plugins({
    click_drag: true
});

관련 자료​

Article: DnD로 작업 생성/선택하기

API: click_drag

Create new tasks by Drag and Drop

자동 스케줄링​

정보

이 확장 기능은 PRO 버전에서만 사용할 수 있습니다

이 기능은 작업 간의 관계를 기반으로 작업을 자동으로 스케줄링합니다.

gantt.plugins({
    auto_scheduling: true
});

관련 자료​

Article: 자동 스케줄링

API: auto_scheduling

Auto Scheduling extension

주요 경로(Critical path)​

정보

이 확장 기능은 PRO 버전에서만 사용할 수 있습니다

프로젝트 전체가 지연되지 않으려면 반드시 제시간에 완료되어야 하는 작업의 순서를 표시합니다. 또한 프로젝트의 최단 소요 기간도 보여줍니다.

gantt.plugins({
    critical_path: true
});

관련 자료​

Article: Critical Path

API: highlight_critical_path

Critical path

타임라인 드래그​

마우스를 드래그하여 타임라인 뷰를 스크롤할 수 있게 해줍니다.

gantt.plugins({
    drag_timeline: true
});

관련 자료​

API: drag_timeline

Drag timeline

추가 오버레이​

정보

이 확장 기능은 PRO 버전에서만 사용할 수 있습니다.

Gantt 차트 위에 추가 레이어를 추가하여 사용자 지정 콘텐츠를 배치할 수 있습니다.

gantt.plugins({
    overlay: true
});

관련 자료​

Article: 타임라인 영역의 커스텀 요소

Gantt chart with overlay and zoom (S-Curve)

내보내기 서비스​

온라인 내보내기(export) 서비스를 사용할 수 있습니다.

gantt.plugins({
      export_api: true
});

전체 화면​

Gantt 차트를 전체 화면 모드로 표시합니다.

gantt.plugins({
    fullscreen: true
});

관련 자료​

그룹화​

정보

이 확장 기능은 PRO 버전에서만 사용할 수 있습니다

작업 속성에 따라 작업을 그룹화할 수 있습니다.

gantt.plugins({
    grouping: true
});

관련 자료​

Article: 작업 그룹화

Tasks grouping

키보드 내비게이션​

Gantt 차트 내에서 키보드를 사용해 이동할 수 있습니다.

gantt.plugins({
    keyboard_navigation: true
});

관련 자료​

다중 작업 선택​

Gantt 차트에서 여러 작업을 동시에 선택할 수 있습니다.

gantt.plugins({
    multiselect: true
});

관련 자료​

빠른 정보(Quick info)​

작업의 세부 정보를 팝업으로 표시합니다.

gantt.plugins({
    quick_info: true
});

관련 자료​

툴팁​

화면을 복잡하게 만들지 않고도 사용자에게 추가 정보를 제공합니다.

gantt.plugins({
    tooltip: true
});

관련 자료​

Article: Gantt 요소의 툴팁

Tooltip

실행 취소(Undo)​

변경 사항에 대한 실행 취소 및 다시 실행 기능을 제공합니다.

gantt.plugins({
    undo: true
});

특정 날짜 또는 날짜 범위를 강조 표시합니다.

gantt.plugins({
    marker: true
});
