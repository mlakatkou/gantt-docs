9.0​

17 октября 2024. Крупное обновление

Обзор релиза в блоге

Важные изменения​

Это обновление вносит изменения в структуру пакета Gantt и поведение функциональности. Обязательно ознакомьтесь с заметками по миграции, чтобы избежать проблем.

Новая функциональность​

  • Настройка скинов с помощью CSS-переменных
  • Новый тёмный скин
  • Добавлена встроенная поддержка baselines
  • Поддержка вручную планируемых суммарных задач
  • Липкие метки для шкалы времени

Обновления​

  • Обновлён Terrace skin
  • Добавлено отображение дедлайнов по умолчанию
  • Добавлено отображение ограничений задач по умолчанию
  • Исходные файлы скинов теперь включены в пакет
  • В Undo plugin добавлены методы setUndoStack и setRedoStack для управления стеками undo/redo
  • Возможность установки профессиональных версий Gantt через npm
  • Библиотека Bluebird Promise удалена из основной библиотеки
  • Различные улучшения масштабирования на экранах с высоким разрешением и отзывчивости на небольших экранах
  • Обновлены определения типов

Исправления​

  • Исправлены некорректные позиции связей для Milestones при увеличенной высоте родительской задачи
  • Исправлена ошибка, возникавшая при автоматическом планировании, если автоматическое планирование отменено для задачи
  • Обеспечено корректное отображение разбитых задач в строке родителя
  • Исправлено автоматическое планирование проектов при наличии связи подзадачи с лагом 0
  • Исправлены некорректные позиции связей для разбитых задач с разной высотой строк
  • Gantt корректно автоматически планирует проекты с двумя уровнями задач
  • Исправлена проблема, при которой Gantt не возвращал fixedDate "assignments" в resource_cell_value, если задача вне указанного диапазона дат
