Настройка задач

📄️ Типы задач

Эта функция доступна только в PRO-версии.

📄️ Свойства задачи

На этой странице представлен полный перечень свойств, которые может содержать объект задачи.

📄️ Task Object/Id

При работе с данными в диаграмме Gantt важно знать, как получить объект или id элемента данных. Большинство методов требуют объект данных или id в качестве параметра. Кроме того, любые операции с данными основываются на ссылке на объект данных или id.

📄️ Task Parent/Child

В этой статье рассматриваются методы, работающие с иерархической структурой задач в диаграмме Gantt.

📄️ Базовые операции с задачами

В этой главе рассматривается, как выполнять основные операции с задачами: создание, удаление и динамическое обновление свойств задачи.

📄️ Незапланированные задачи

В Gantt можно добавить задачи без указанных дат.

📄️ Разделение задач

Эта функция доступна только в редакции PRO.

📄️ Множественный выбор задач

Начиная с версии 3.2, библиотека включает расширение multiselect, которое позволяет выбирать несколько задач одновременно.

📄️ Расчёт рабочего времени

По умолчанию dhtmlxGantt вычисляет длительность задач по календарному времени, то есть выходные и праздничные дни включаются в общее время.

📄️ Критический путь

Эта функция доступна только в редакции PRO.

📄️ Дополнительные элементы на временной шкале

Эта функция доступна только в PRO-версии

📄️ Пользовательские элементы в области временной шкалы

Эта функция доступна только в редакции PRO.

📄️ Вехи

Эта функциональность доступна только в PRO-версии

📄️ Тултипы для элементов Gantt

Тултипы позволяют отображать дополнительную информацию, не перегружая экран лишним текстом. По умолчанию тултипы появляются на задачах Gantt.

📄️ Отображение содержимого задач

Рядом с полосой задачи может отображаться метка, содержащая дополнительные сведения о задаче. Обычно здесь указывается информация, такая как назначенные ресурсы: люди, материалы и так далее.

📄️ Режим только для чтения

В этом разделе рассмотрим режим только для чтения в двух сценариях:

📄️ Валидация

Валидация помогает обеспечить точность данных, вводимых пользователями, и предотвращает сохранение некорректных значений. Например, это может предотвратить назначение двух задач одному сотруднику в одно и то же время.

📄️ Перетаскивание задач на временной шкале

Перетаскивание облегчает изменение дат начала и окончания задач, а также их длительности.

📄️ Создание/Выделение задач с помощью DnD

Библиотека dhtmlxGantt предоставляет расширение, которое добавляет расширенные возможности drag-and-drop для управления задачами на временной шкале.

📄️ Вручную запланированные сводные задачи

Можно вручную планировать проекты (сводные задачи), чтобы получить больше контроля и точности при работе с диаграммами Gantt.

📄️ Перетаскивание задач вместе с их зависимыми задачами

Существует несколько способов перемещения задач вместе с их зависимыми задачами.
